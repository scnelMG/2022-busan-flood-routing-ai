# 재현성 및 검증 상태

## 현재 공개본의 목적

이 저장소는 원본 팀 프로젝트를 그대로 실행 가능한 형태로 재배포하지 않습니다. 데이터 접근 권한이 없는 독자가 **입력 계약, 전처리 순서, 분류 검증 원칙, Q-learning 보상 설계**를 검토할 수 있도록 만든 공개용 워크스루입니다.

## 검증된 항목

- 공개 노트북은 출력·실행 번호·개인 메타데이터 없이 유효한 Jupyter Notebook JSON으로 저장됩니다.
- 공개 트리의 금지 확장자·비공개 경로·민감한 경로 문자열은 `scripts/validate-public-release.ps1`로 검사합니다.
- 노트북은 학습/검증 분할 후 학습 데이터에만 SMOTE를 적용하도록 작성했습니다.

## 실행하지 않은 항목과 이유

공개본에는 재배포가 승인된 입력 데이터가 없으므로, 노트북 전체 실행과 모델 점수·경로 품질 평가는 수행하지 않았습니다. 이 저장소는 그러한 결과를 주장하지 않습니다.

적법하게 준비한 비공개 입력이 있다면 다음 명령으로 별도 환경에서 실행을 확인할 수 있습니다.

```powershell
python -m jupyter nbconvert --execute --to notebook --inplace notebooks/flood-routing-modeling.ipynb
```

필수 조건은 Python 환경, `requirements.txt`의 패키지, 그리고 [데이터 출처와 공개 경계](data-sources.md)의 입력 계약을 만족하는 두 CSV입니다. 실행 결과는 기본적으로 개인 작업 공간에만 보관하고, 재공개 전에는 데이터·라이선스·팀 동의를 다시 검토해야 합니다.

## 해석상의 한계

- 단일 프로젝트의 예제 설계이며 지역·시점·입력 품질이 달라지면 성능과 정책이 달라질 수 있습니다.
- Q-learning 보상은 의사결정 실험을 설명하기 위한 예시입니다. 실제 교통 통제나 재난 대응 권고에 사용하려면 별도 안전성·현장 검증이 필요합니다.
- 모델의 성능·일반화·안전성을 판단할 수 있는 공개 근거는 이 저장소에 포함하지 않습니다.
