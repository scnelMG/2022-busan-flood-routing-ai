# 데이터 출처와 공개 경계

## 사용한 데이터 범주

원본 팀 프로젝트는 다음 범주의 정보를 결합해 모델링했습니다.

| 범주 | 예시 특성 | 공개 저장소 포함 여부 |
| --- | --- | --- |
| 침수 이력·공간 정보 | 격자별 침수 라벨, 위치 기반 정보 | 포함하지 않음 |
| 지형 정보 | 고도, 경사도 | 포함하지 않음 |
| 배수 시설 정보 | 펌프·저류시설과의 거리 및 용량 | 포함하지 않음 |
| 기상 정보 | 시간당 강수량 | 포함하지 않음 |
| 도로 네트워크 | 노드, 링크, 거리, 침수 상태 | 포함하지 않음 |

원본 작업에서 참조한 출처 범주는 공공데이터포털의 침수·배수시설·표준노드링크 자료, 국가공간정보 관련 지형 자료, 기상자료개방포털의 강수 자료입니다. 이 목록은 출처 범주를 설명하기 위한 것이며, 특정 파일·추출물·계정·요청 기록을 제공하지 않습니다.

## 왜 데이터를 공개하지 않는가

원본 입력에는 팀 작업 과정에서 생성된 공간 결합·전처리 결과가 포함될 수 있으며, 데이터별 재배포 조건과 팀 동의 여부를 이 저장소에서 확정할 수 없습니다. 따라서 모든 원시·중간·결과 데이터는 공개 범위에서 제외합니다.

## 재현을 위한 최소 입력 계약

별도의 적법한 데이터 접근 권한이 있는 경우에만 다음과 같은 스키마를 준비할 수 있습니다.

- `flood_features.csv`: `flood_label`, `elevation`, `slope`, `storage_distance_m`, `storage_capacity`, `pump_distance_m`, `pump_capacity`, `hourly_rainfall`
- `road_edges.csv`: `from_node`, `to_node`, `length_m`, `is_flooded`

파일명·열 이름은 공개 예제의 계약일 뿐, 원본 데이터 구조나 값을 복제하지 않습니다. 좌표·식별자·개인정보를 포함하지 않는 최소화된 입력을 사용해야 합니다.

## 확인해야 할 사항

재현 전에 각 제공기관의 최신 라이선스, 이용약관, 갱신 주기, 공간정보의 2차 이용 조건을 확인하세요. 이 저장소는 데이터 제공자나 실제 운행 의사결정 시스템을 대리하지 않습니다.
